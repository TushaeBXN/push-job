# Push Job

## ⚡ BIG UPDATE — Aug 25, 2025

**Three upgrades shipping today:**

**1. `/resume` → Gap Disclosure step**
Before rewriting your resume, Push Job now asks you — in your own words — what you've actually done that covers the missing keywords. Use your phone's dictation feature or type it out. Both tools can finish the job. Only real experience gets added, so your resume passes ATS on context — not keyword stuffing that gets filtered out anyway.

**2. New command: `/gigs` — FU Money Mode**
FU money doesn't come from side hustles. Run `/gigs` and Push Job audits your resume for every skill that could earn you remote income today — then maps each one to a master list of niche gig platforms and marketplaces, including ones you've probably never heard of. Start adding yourself today.

**3. `/interview` upgraded — Stage-Based Prep**
Generic interview prep is out. The `/interview` mode now identifies which stage you're in — recruiter screen, hiring manager, panel, executive, or case study — and builds everything around what that specific interviewer is actually evaluating. Each stage has a completely different strategy, and now the agent knows the difference.

An AI-powered job search pipeline built on Claude Code — paste a job URL and get a full evaluation, tailored resume, cover letter, cert gap analysis, and tracker entry in one shot.

## What it does

- Evaluates any job posting against your background using a 12-dimension scoring system — role fit, tech stack, cert alignment, compensation, growth trajectory, and more
- Generates a tailored resume and cover letter specific to each role, researches the company before writing, and tracks every application automatically
- Monitors your pipeline daily — follow-up reminders, cert recommendations, and a morning brief to keep you moving

## What makes it different

- 15 slash command modes covering the full job search lifecycle, including cert gap analysis, follow-up scheduling, salary negotiation, and portfolio sync
- Portal list built specifically for cloud and cybersecurity — Cloudflare, CrowdStrike, SentinelOne, Rapid7, HashiCorp, Booz Allen, Leidos
- Single Node.js stack, no additional dependencies

## Quick start

1. Clone the repo and run `npm install`
2. Open the folder in Claude Code
3. Run `/check` to verify your setup
4. Run `/evaluate [job URL]` to score your first job

## Slash commands

- `/evaluate [URL]` — score a job posting across 12 dimensions
- `/cover [URL or company]` — write a researched cover letter
- `/resume [URL or company]` — tailor your resume for a specific role
- `/scan` — scan all portals for new openings
- `/batch [URL list or file]` — evaluate multiple jobs at once
- `/tracker` — view your full application pipeline
- `/interview [company or role]` — stage-based interview prep
- `/certs` — cert gap analysis across all tracked jobs
- `/followup` — draft follow-up messages for open applications
- `/brief` — daily pipeline summary
- `/negotiate [offer amount]` — salary negotiation prep
- `/outreach [company or person]` — draft outreach messages
- `/portfolio-sync` — sync your GitHub projects
- `/gigs` — find gig opportunities aligned to your existing skills
- `/help` — print the full command list
