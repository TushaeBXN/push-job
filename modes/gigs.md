# gigs.md — FU Money: Gig Opportunity Finder

**Trigger:** `/gigs`

> **⚡ NEW — Aug 25, 2025**
> FU money doesn't come from side hustles — it comes from aligned work that uses skills you've already built. This mode audits your resume for every skill that can earn remotely today and maps each one to niche gig platforms and marketplaces, including ones you've probably never heard of.

---

## Step 1 — Load Resume (Anonymized)

Read `resume.md`.

Before processing, mentally strip all personal identifiers — name, email, phone, address. Only skills and experience matter here.

---

## Step 2 — Skill Audit for Remote Pay

Analyze the resume for every skill that someone would pay for remotely — including skills Brian may not think of as marketable:

- Technical skills (cloud, security, scripting, automation)
- Operational skills (logistics, compliance, process management, scheduling)
- Communication skills (writing, training, documentation, customer service)
- Domain knowledge (postal operations, government systems, workforce management)
- AI/tooling skills (Claude, Python, Playwright, prompt engineering)

For each skill, explain **why people pay for it** and **what type of work it unlocks**.

---

## Step 3 — Build the Gig Platform Master List

For every skill identified, list every relevant platform — go deep beyond Upwork and Fiverr. Include:

- Niche freelance marketplaces specific to that skill
- Remote job boards that accept project-based work
- Consulting directories and talent networks
- Platform cooperatives and community hiring pools
- Government and enterprise contractor portals where applicable

Format as a table per skill:

```
SKILL: [name]
Why it pays: [one sentence]

Platform              | URL                        | How to position yourself
----------------------|----------------------------|--------------------------
[Platform name]       | [url]                      | [what to offer / profile tip]
...
```

---

## Step 4 — Quick Wins

Surface the 3–5 platforms where Brian can create a profile and start getting inquiries fastest — based on his strongest, most in-demand skills.

```
QUICK WINS — Start Here Today
1. [Platform] — [url] — [why this one first]
2. ...
```

---

## Step 5 — Save Output

Ask: "Do you want me to save this to `data/gig-opportunities.md`?"

If yes, write the full output there for future reference.

---

## Rules

- Never fabricate skills not in the resume
- Flag skills that need one small certification or portfolio piece to unlock higher-paying tiers
- Prioritize platforms where Brian can start with zero upfront cost
- Quality over quantity — a focused list of real platforms beats a padded list of irrelevant ones
